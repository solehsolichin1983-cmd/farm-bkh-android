# FARM BKH Android V1.0a

Android WebView wrapper untuk FARM BKH Web GAS.

## Cloud Build
Push ke branch `main` akan menjalankan GitHub Actions dan menghasilkan artifact APK bernama `FARM_BKH_ANDROID_V1.0a_APK`.

Fitur utama:
- Fullscreen WebView
- Pull-to-refresh
- Offline page + Retry
- Back navigation
- Google Apps Script / Web GAS support
- External links dibuka di browser
